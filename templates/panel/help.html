How to use this panel

The short version — everything is point-and-click.

1

Add a module

Go to Modules → Add module. Choose the plant and department, write a title and summary, add a cover photo. New modules start as Draft (hidden from learners).

2

Add SOP steps

Open the module → SOP steps. Add steps one by one, or paste a whole list / import an Excel file. Use the arrows to reorder; numbering is automatic.

3

Add safety rules & photos

Safety rules must be agreed by learners before steps unlock. Photos make the Overview tab come alive — learners can tap to enlarge them.

4

Create the quiz

Module → Quiz → Create quiz → add questions (or import). Questions and answer options are shuffled on every attempt automatically.

5

Add Hindi

Every form has a collapsed Hindi (optional) section — add translations there. Learners who choose Hindi see them (and the read-aloud speaks Hindi).

6

Publish

Click Preview as learner to check it, then Publish. You can hide it again anytime with Hide from learners.

Good to know

  • Nothing is lost by mistake: rows you remove are only deleted when you press Save changes. If you leave with unsaved edits, the browser warns you.
  • Photos are shrunk automatically — upload straight from your phone.
  • SOP versions: mark a version Approved to make it the one learners see; the older approved one becomes Superseded automatically.
  • Users: add them one by one or import from Excel. Untick Restrict to these plants to give access to everything.
  • Learner view: use Preview as learner in your account menu to see the app exactly as learners do.
